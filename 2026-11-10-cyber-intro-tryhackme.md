# Offensive Security Intro
*Platform:* TryHackMe | *Date:* 2026-11-10 | *Status:* Completed

## What I learned
- Offensive security means thinking like an attacker to find weaknesses before real attackers do.
- Ethical hackers (red team / pen testers) get permission first.

## Key terms
- *Vulnerability:* a weakness in a system
- *Exploit:* using a weakness
- *Pentest:* authorized security test
